Proyectos

Algunos de nuestros trabajos recientes

Terra Pot

Landing Page para un e-commerce de plantas decorativas para interiores y exteriores. Utilizando técnicas modernas de desarrollo y con enfoque mobile first para asegurar que se pueda abrir la página en cualquier dispositivo.

Congresos Udeo

Sistema desarrollado para la Universidad de Occidente para la gestión de los congresos realizados para cada facultad, cuenta con autenticación, generación de tickets, registro de alumnos, catedráticos, conferencistas.

Sistema para clínica

Sistema desarrollado para clínica cardiológica. Permite el registro y gestión de pacientes, citas médicas, inventario de medicinas y facturación generadas electrónicamente con inicio de sesión.
